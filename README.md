# LLM Essay Evaluator

An LLM-powered essay evaluation system built using **LangGraph, LangChain, Groq, and Pydantic**. The system evaluates essays across three criteria — clarity of thought, depth of analysis, and language quality — and generates an overall assessment with an average score.

## 🚀 Features

- **Parallel Evaluation:** Evaluates clarity, analytical depth, and language using separate LangGraph nodes.
- **Structured Outputs:** Uses Pydantic to obtain structured feedback and scores from 0 to 10.
- **State Management:** Uses LangGraph state updates and reducers to collect scores from parallel nodes.
- **Overall Feedback:** Combines individual evaluations into a summarized assessment.
- **Average Score:** Calculates the average score across the three evaluation criteria.
- **Groq Integration:** Uses a Groq-hosted language model through LangChain.

## 🛠️ Tech Stack

- Python
- LangGraph
- LangChain
- Groq API
- Pydantic
- python-dotenv

## 🧠 How It Works

The workflow processes an essay through three parallel evaluation nodes.

1. **Clarity Evaluation:** Assesses how clearly the essay communicates its ideas.
2. **Analysis Evaluation:** Evaluates the depth of reasoning and supporting arguments.
3. **Language Evaluation:** Examines grammar, vocabulary, and readability.
4. **Overall Evaluation:** Combines the feedback from all three evaluators.
5. **Score Calculation:** Computes the average of the three individual scores.

### Workflow Architecture

```text
                Input Essay
                     |
          +----------+----------+
          |          |          |
       Clarity    Analysis   Language
      Evaluation Evaluation Evaluation
          |          |          |
          +----------+----------+
                     |
             Overall Feedback
                     |
              Average Score
                     |
                    END
```

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/llm-essay-evaluator.git
cd llm-essay-evaluator
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Create a virtual environment

```bash
python -m venv myvenv
```

Activate it on Windows:

```bash
myvenv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure the API key

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Get an API key from the [Groq Console](https://console.groq.com/keys).

**Security:** Never commit your `.env` file or expose your API key publicly.

### 5. Run the project

```bash
python upse_essay_rater.py
```

## 📊 Output

For each essay, the system returns a state containing:

- Clarity feedback
- Analysis feedback
- Language feedback
- Overall summarized feedback
- Individual evaluation scores
- Average score out of 10

The exact feedback and scores depend on the essay and the language model's evaluation.
